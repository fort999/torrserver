# TorrServer MatriX for Home Assistant

**TorrServer MatriX** — программа для потокового воспроизведения торрентов онлайн без необходимости предварительной загрузки всего файла.

## Возможности
- Потоковый просмотр видео с торрентов через плееры (VLC, Vimu, Kodi, Nova, ExoPlayer и др.)
- Интеграция с медиа-каталогами (Lampa, NUM, LazyMedia Deluxe и т.д.)
- Поддержка Home Assistant Ingress (управление сервером в боковой панели HA)
- Поддержка прямого сетевого порта `8090` для ТВ-приставок, смарт-ТВ и мобильных устройств
- Сохранение кэша и базы торрентов в постоянное хранилище Home Assistant (`/data`)

## Конфигурация аддона

Пример конфигурации:
```yaml
port: 8090
httpauth: false
logins: []
proxyurl: ""
proxymode: "disabled"
weblog: false
dontkill: false
rdb: false
tgtoken: ""
```

### Описание параметров

| Параметр | По умолчанию | Описание |
|---|---|---|
| `port` | `8090` | Сетевой порт для веб-интерфейса и потокового видео |
| `httpauth` | `false` | Включить HTTP аутентификацию (логин/пароль) |
| `logins` | `[]` | Список пользователей и паролей при включенной аутентификации |
| `proxymode` | `disabled` | Режим работы прокси (`disabled`, `tracker`, `peers`, `full`) |
| `proxyurl` | `""` | Адрес прокси-сервера (например, `http://user:pass@host:port` или socks5) |
| `weblog` | `false` | Логирование входящих HTTP-запросов веб-сервера в журнал |
| `dontkill` | `false` | Не останавливать воспроизведение/раздачу торрента при отключении клиента |
| `rdb` | `false` | Режим базы данных «только чтение» |
| `tgtoken` | `""` | Токен Telegram-бота для уведомлений |

## Подключение клиентов (Lampa / NUM / Kodi)
В настройках клиента укажите адрес сервера:
- `http://<IP_АДРЕС_HOME_ASSISTANT>:8090`
