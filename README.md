# TorrServer MatriX Home Assistant Add-on Repository

Репозиторий аддона **TorrServer MatriX** для Home Assistant.

## Что внутри
Аддон на базе релиза [TorrServer MatriX (bylampa/Matrix)](https://github.com/bylampa/Matrix/releases/tag/MatriX.145.UN).

- **Версия:** MatriX.146.UN
- **Поддерживаемые архитектуры:** `amd64`, `aarch64` (ARM64 / Raspberry Pi 3/4/5 64-bit), `armv7` (Raspberry Pi 32-bit), `i386`
- **Веб-интерфейс:** доступен через Ingress в боковой панели Home Assistant и/или по порту `8090` (для Lampa, Kodi, Vimu, Android TV и т.д.)
- **Постоянное хранение:** настройки и торренты сохраняются в каталоге данных аддона (`/data`).

## Установка

### Способ 1: Локальный аддон (Local Add-on)
1. Подключитесь к вашему Home Assistant через Samba share, SSH или файловый менеджер.
2. Скопируйте папку `torrserver` в каталог `/addons/` на вашем сервере Home Assistant (получится `/addons/torrserver/`).
3. В Home Assistant перейдите в **Настройки** -> **Дополнения** -> **Магазин дополнений** (Add-on Store).
4. Нажмите три точки в правом верхнем углу -> **Проверить обновления** (Check for updates).
5. В списке появится раздел **Local add-ons**, выберите **TorrServer MatriX** и нажмите **Установить**.

### Способ 2: Через репозиторий GitHub
1. Опубликуйте данную папку в свой репозиторий GitHub.
2. В Home Assistant перейдите в **Настройки** -> **Дополнения** -> **Магазин дополнений**.
3. В правом верхнем углу меню (три точки) -> **Репозитории** (Repositories).
4. Добавьте URL вашего репозитория и нажмите **Добавить**.
5. Установите аддон из каталога.

## Настройка
После установки в настройках аддона доступны опции:
- `port`: порт веб-интерфейса и стриминга (по умолчанию `8090`).
- `httpauth`: включение авторизации (по умолчанию `false`).
- `logins`: список пользователей и паролей при включенной авторизации.
- `cache_size`: размер кэша в оперативной памяти (МБ).
- `proxyurl` и `proxymode`: настройки работы через прокси.
- `weblog`: расширенный вывод логов веб-сервера.
